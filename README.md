# gpuix-app-starter

[简体中文](README.zh-CN.md)

A runnable React + GPUIX application generated by
[`gpuix-android`](https://github.com/wdcodecn/gpuix-android). It demonstrates
[`gpuix-base-ui`](https://github.com/wdcodecn/gpuix-base-ui) on the native
Android host: standalone Hermes executes JavaScript and GPUI/wgpu renders the
interface without a WebView or React Native view hierarchy.

## Run the demo

```sh
gh repo create my-app --public \
  --template wdcodecn/gpuix-app-starter \
  --clone
cd my-app
bun install
bun run typecheck
bun run dev
```

On Android:

```sh
bun run gpuix:doctor
bun run gpuix:build
bun run gpuix:run -- <ADB_SERIAL>
```

## Build artifacts

```sh
gpuix build             # debug APK
gpuix build --release   # local release APK
gpuix build --aab       # Android App Bundle
```

Artifacts are written to `dist/android/`.

## What to change

- `src/main.tsx`: application UI and state
- `gpuix.android.json`: app ID, display name, version name and version code
- `android/app/src/main/res`: launcher icon and native splash resources

The generated `android/` directory is intentionally committed, following the
same inspectable platform-project model used by established mobile toolchains.
Framework fixes belong in `gpuix-android`; reusable components belong in
`gpuix-base-ui`; this repository remains a small example application.

## Release note

The included local release configuration uses a debug keystore. Configure a
real upload key before distributing through Google Play.
